# Server-rules checklist

Hopup Creator is an educational guide. It is not approval to use a third-party add-on on any server.

Before each server session:

1. Read the server's current rules, Discord guidance and anti-cheat/add-on policy.
2. Ask staff if the rules are unclear.
3. If third-party assets, ReShade add-ons or route guides are banned, do not install or enable this tool there.
4. Disable it and remove the `.addon64` before joining a server where it is not permitted.
5. Never use it to bypass anti-cheat, automate movement or gain information the server does not allow.

Arena and EchoRP are examples that have been raised as potentially restrictive. This project does not verify or guarantee their current policy. Rules can change.
